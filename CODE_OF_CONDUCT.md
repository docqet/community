# Code of Conduct

Docqet is maintained by Exalynt and follows the
[Exalynt Code of Conduct](https://github.com/exalynt/community/blob/main/CODE_OF_CONDUCT.md).
It covers everyone taking part in Docqet: its repositories, issues, pull
requests, discussions and any other Docqet space.

In short: be respectful, criticize ideas and code rather than people, and
disagree in good faith. Harassment, personal attacks and discrimination
aren't tolerated.

To report a problem, contact the Exalynt maintainers privately, as the Code
of Conduct describes. Reports are shared only with the people who need them
to respond.
