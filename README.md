# Docqet Community

Welcome to the Docqet community.

[Docqet](https://github.com/docqet/docqet) is an open format, and the tools
that read it, for writing down what your software is meant to do beside the
code, linked to the evidence of what it actually does. This repository is the
community hub for the Docqet GitHub organization: where conversations happen,
and how we contribute, behave and make decisions across every Docqet
repository.

> [!WARNING]
> Docqet is a **Prototype**. The format, the commands and the UI may all
> change a lot. This is a good time to help shape it.

## Discussions

[GitHub Discussions](../../discussions) is the place for anything that isn't
a bug or a concrete change to one repository.

- **Q&A**: questions about using Docqet, writing its docs, or the agent kit.
- **Ideas**: ideas for Docqet, the format or the tools. Start larger ideas
  here before opening an issue.
- **Show and tell**: projects you've documented with Docqet, and what you
  learned.
- **Announcements**: news from the maintainers, such as changes to the
  format.
- **General** and **Polls**: everything else.

Bugs and actionable changes belong in the issues of the repository they're
about, such as [docqet/docqet](https://github.com/docqet/docqet/issues).

## Contributing

Contributions are welcome: questions, bug reports, ideas, docs, examples,
tests and code. You don't need to write code to help.

Read the [contributing guide](CONTRIBUTING.md) first. Each repository's own
`CONTRIBUTING.md` adds what's specific to it.

## Governance

Docqet is open source and maintained by [Exalynt](https://github.com/exalynt).
Anyone can propose ideas and changes; maintainers decide. See
[GOVERNANCE.md](GOVERNANCE.md).

## Code of Conduct

Docqet follows the [Exalynt Code of Conduct](CODE_OF_CONDUCT.md). Disagree
about ideas and code as much as you like, and respect the people behind them.

## Security

Please don't report a vulnerability in a public issue or discussion. Follow
the `SECURITY.md` of the affected repository, such as
[docqet/docqet's](https://github.com/docqet/docqet/blob/main/SECURITY.md).
